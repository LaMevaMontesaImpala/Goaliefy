Methodology & Kinematic Engine

Goaliefy calculates specialized field hockey metrics using advanced computer vision frames and spatial geometry modeling.

Reaction Time (s)

Measured from the initial stick-ball separation frame to the first defensive muscle twitch or lateral displacement frame.

Slide / Rush Velocity (m/s)

Calculated via pixel-displacement calibration over time from set position to the execution point of the sliding save.

Angular Coverage (%)
